# CalcudadoraCSharp

Uma aplicação de calculadora desktop desenvolvida em **C#, Windows Forms e .NET**.

Este projeto foi desenvolvido como exercício prático de programação, com foco na construção de interfaces gráficas, manipulação de eventos e implementação de operações matemáticas.

## Download

**[Baixar Calculadora Windows x64](https://github.com/GPS33/CalculadoraCSharp/releases/latest)**

A versão disponibilizada é independente do runtime .NET, não exigindo uma instalação separada do .NET.

**Como executar:**
1. Baixe o arquivo ZIP na seção Releases.
2. Extraia seu conteúdo.
3. Execute `Calculadora.exe`.

Requisitos: Windows x64.

## Funcionalidades

- Interface gráfica desenvolvida com Windows Forms.
- Operações aritméticas básicas: adição, subtração, multiplicação e divisão.
- Entrada de números por meio de botões.
- Botões de limpeza e controle de operações.
- Cálculo de porcentagem.

## Tecnologias utilizadas

- **C#** — Linguagem de programação.
- **.NET 10** — Plataforma de desenvolvimento.
- **Windows Forms** — Framework para construção da interface gráfica.
- **Visual Studio** — Ambiente de desenvolvimento.
